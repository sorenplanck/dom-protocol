# DOM Scriptless Contracts — isolated fork rules

- This repository is the local development fork for DOM Scriptless Contracts.
- `/home/leonardov/dom-release` and `/home/leonardov/dom-wallet-v3` are read-only official sources. All development occurs in clones under `/home/leonardov/dom-scriptless-dev`.
- All new or modified project code, comments, tests, commit messages, and documentation must be written in English. Portuguese is restricted to operator chat.
- DL2P, `DL2P-*` files, `rfc000*.py` models, legacy L2 specifications, and DL2P consensus changes are outside this project.
- Integration into official repositories may be considered only after implementation is complete and tests pass. Push, merge, release, and publication are prohibited in this environment.
- Phase 1 corresponds to the `dom-adaptor` crate and must not change consensus, genesis, network magic, serialization, protocol, wire formats, or persisted blocks.
- The laboratory provides evidence and candidate fixtures, never authoritative implementation.
- Commits must be small, auditable, and scoped.
- Frozen fixtures must not be regenerated by the same code under test.
- Do not invent formats, hash tags, purposes, policies, or numeric limits.
- Do not duplicate DOM's authoritative Schnorr, BLAKE2b, point parser, challenge, or verifier.
- Do not use `unsafe`, `todo!()`, `unimplemented!()`, or mocks that could be mistaken for production code.
- Production requires both G1a and G1b approval; bootstrap and parameter freeze do not authorize production cryptography.
