# Integration tests

The integration suite exercises canonical parsers, frozen purposes and hash
framing, collective nonce binding, pre-signature verification, adaptation, and
extraction. All eight frozen SCAD0 records are adapted byte-for-byte and passed
through `dom_consensus::validate_kernel_signatures`.

The SCAD0 corpus is frozen evidence but is not treated as an independent
two-nonce implementation. Tests generated by the DOM implementation under test
are never labeled independent.
